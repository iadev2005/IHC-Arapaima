# 🌊 Proyecto Arapaima - Cultura del Agua

Una plataforma web interactiva para concientizar sobre la importancia del agua y fomentar prácticas sostenibles, siguiendo los principios de la UNESCO (2006) sobre la cultura del agua.

## 🚀 Tecnologías

- **React 19** - Framework principal
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Estilos y diseño
- **Framer Motion** - Animaciones
- **Vite** - Build tool y desarrollo
- **React Router** - Navegación

## 📁 Estructura del Proyecto

```
src/
├── components/          # Componentes React organizados
│   ├── ui/             # Componentes base (Button, Input, etc.)
│   ├── shared/         # Componentes reutilizables
│   ├── layout/         # Componentes de layout
│   └── features/       # Componentes específicos
├── pages/              # Páginas organizadas por dominio
│   ├── home/           # Página principal
│   ├── forum/          # Foro de discusión
│   ├── culture/        # Cultura y artículos
│   ├── water/          # Información sobre agua
│   ├── library/        # Biblioteca de recursos
│   └── map/            # Mapa interactivo
├── data/               # Datos estáticos por dominio
├── services/           # Servicios de negocio
├── types/              # Tipos TypeScript
├── hooks/              # Hooks personalizados
├── utils/              # Utilidades generales
└── constants/          # Constantes de la aplicación
```

## 🎯 Funcionalidades

- **Foro Interactivo**: Discusiones sobre cultura del agua
- **Biblioteca de Recursos**: Artículos y materiales educativos
- **Información sobre Agua**: Datos sobre peces, ríos y calidad del agua
- **Mapa Interactivo**: Visualización geográfica
- **Cultura y Tradiciones**: Artículos sobre costumbres relacionadas con el agua

## 🛠️ Desarrollo

### Instalación
```bash

```

### Desarrollo
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Linting
```bash
npm run lint
```

## 📋 Convenciones

- **Componentes**: PascalCase (`ForumPage.tsx`)
- **Hooks**: camelCase con prefijo `use` (`useForm.ts`)
- **Utilidades**: camelCase (`formatDate.ts`)
- **Tipos**: PascalCase (`ForumData.ts`)
